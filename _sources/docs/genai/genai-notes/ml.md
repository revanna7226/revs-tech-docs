# Machine Learning

There are two major tasks we perform

1. Classification
   Classification of the data using ML programs.
   - Binary Classification
   - Multiclass Classification

   Examples:
   1. Email Spam Classification
   2. Fraud Detection
   3. Image Classification

2. Regression
   No discrete catogories, but when we have wide varity of catagories.

   Examples:
   - Property Price prediction
   - Salary Prediction
   - Stock price prediction

Categories of Machine Learning

1. Supervised Learning
   Trained with labelled data.
2. Un-supervised Learning
   We provide an unlabeled dataset to an ML program and then it learns to identify patterns and structures in data without any explicit guidance.
